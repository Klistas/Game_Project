## 0. 원 센텐스 피치

**"자동차 바퀴를 오려 상자에 붙이면 굴러가고, 새 날개를 의자에 붙이면 날아간다 — 가위 하나로 세상 모든 부위를 재조합하는 물리 퍼즐."**

### 시장 근거
- "내가 만든 괴상한 물체"는 UGC성 바이럴의 정점 — 스크린샷/클립이 유저 손에서 무한 생산됨
- Human Fall Flat, Gang Beasts 계열이 증명한 "물리가 곧 개그" 수요 + 퍼즐 구조로 스코프 통제
- 직관성 최상: 트레일러 5초면 게임 전체가 이해됨

### 리스크와 대응 (배치 내 최고 난이도인 이유)
- **자유 절단 금지 (확정):** 모든 엔티티는 **미리 정의된 부위 슬롯**(바퀴/날개/입/다리/손잡이/눈 6계열)만 분리 가능. 자유 메시 절단은 개발 지옥
- **물리 버그 = 이 장르에선 절반은 콘텐츠, 절반은 리뷰 폭탄** → "웃긴 버그"(물체가 우스꽝스럽게 구름)는 허용, "진행 불가 버그"(끼임/소실)는 자동 복구 시스템으로 원천 차단 (아래 2.4)
- 에셋을 부위 단위로 제작해야 함 → 아트 규격 문서를 Phase 0에서 확정 (부위별 앵커/조인트 규격 통일)

## 1. 코어 루프

```
스테이지 입장 → 목표 확인 ("강 건너편으로 이동하라")
→ 가위 모드: 절단 가능 부위가 점선으로 표시됨
→ 부위 오려내기 (인벤토리 최대 3부위)
→ 대상에 붙이기: 슬롯 스냅 (호환 슬롯이면 어디든)
→ 물리 시뮬 시작: 조합물이 실제로 작동/폭주
→ 목표 달성 or 물리적 대참사 (즉시 리트라이)
→ 별점 + 신규 부위 계열 해금 → "괴물체 도감"에 내 조합 기록
```

**구조:** 4챕터 × 12스테이지 = 48 + 자유 조립 놀이터(샌드박스).
**세션:** 스테이지당 4~10분. **플레이타임:** 6~9시간 + 샌드박스.

## 2. 시스템 설계

### 2.1 부위 시스템 (6계열 — 절대 초과 금지)
| 계열 | 기능 태그 | 물리 구현 |
|---|---|---|
| 바퀴 | Roll | WheelJoint2D + 모터 |
| 날개 | Fly | 주기적 상향 임펄스 + 항력 |
| 다리 | Walk | 2관절 프로시저럴 보행 (개그 보행 허용) |
| 입 | Bite/Eat | 트리거 콜라이더 + "삼킴"(오브젝트 흡수) |
| 손잡이 | Openable | 부착 대상에 "열림" 상호작용 부여 (벽→문) |
| 눈 | See/Aim | 부착 대상이 대상 추적/회피 AI 획득 |
- 부위 = `PartSO`: 계열/질량/파워/조인트 앵커 규격/사운드
- **조합 태그:** 바퀴+눈 = 자율주행, 날개+입 = 사냥 드론... 파생 규칙은 소수 수제작, 나머지는 물리가 알아서 만드는 창발에 맡김
- 몸통(베이스) 15종: 상자/의자/자동차(부위 도너)/새/로봇/문/바위/괴물 등 — 도너 겸 베이스

### 2.2 부착/물리 규칙
- 슬롯 스냅: 부위를 들면 대상의 호환 앵커가 발광 → 근접 시 자석 스냅 (정밀 조작 불요 — 접근성)
- 부위 수에 따른 물리 예산: 몸통당 최대 부위 4개 (성능+개그 밀도 유지)
- 질량/무게중심 자동 재계산 → "바퀴 한쪽만 단 상자"가 뒤뚱대는 것 자체가 개그

### 2.3 스테이지 & 목표
- 목표 유형: 이동(강 건너기), 파괴, 운반, 유인(입 달린 금고로 경비 삼키기), 탈출
- 챕터: 고물상 → 동물원(!) → 공장 → 마법사의 탑
- 별점: 목표 달성 / 부위 2개 이하 / 개그 조건(특정 괴물체 제작) — 리플레이 축

### 2.4 안정성 시스템 (리뷰 방어의 핵심)
- 스테이지 경계 이탈/끼임 감지 → 3초 내 자동 되감기(직전 안정 상태 복원, 페널티 없음)
- 조합물 저장/불러오기 (샌드박스) + 괴물체 도감: 스크린샷 자동 캡처 → 공유 버튼 (스팀 스크린샷 연동) — **UGC 바이럴 장치**
- 리플레이 GIF 내보내기 (마지막 15초) — 클립 생산을 게임이 대신함

## 3. 아트/사운드 방향

- **비주얼:** 콜라주/잡지 오려붙이기 스타일 (사진 질감 + 흰 절단 테두리) — "오려 붙인다"는 메커닉과 아트가 하나. 절단면은 항상 흰 종이 단면
- 가위 커서, 오릴 때 "사각" 사운드, 붙일 때 테이프 "찌익" — 문구류 ASMR로 손맛 통일
- 부위가 붙는 순간 조합물이 부르르 떨며 깨어나는 연출 (프랑켄슈타인 모먼트)
- 캡슐: 날개와 자동차 바퀴가 붙은 의자가 하늘을 나는 장면

## 5. 개발 로드맵 (Claude Code Phase)

### Phase 0 — 물리 프로토타입 (세션 3~4회) ★기술 검증이 곧 게이트
- [ ] 부위/앵커 규격 문서 확정 (`docs/PART_SPEC.md` — 이후 모든 아트 발주 기준)
- [ ] 절단(슬롯 분리)/부착(자석 스냅)/조인트 생성 파이프라인
- [ ] 바퀴/날개/다리 3계열 물리 구현 + "강 건너기" 스테이지 4개 (도형 그래픽)
- [ ] 끼임/이탈 자동 되감기 1차
- **DoD/게이트:** ①조합물이 "예상 밖이지만 물리적으로 납득되게" 움직이는가 ②프로토 클립 외부 반응 ③치명적 물리 불안정이 통제 가능한가 — **③ 실패 시 즉시 Kill (기술 리스크 게이트)**

### Phase 1 — 버티컬 슬라이스 (세션 5~6회)
- [ ] 콜라주 아트 확정, 몸통 8종/부위 규격 적용, 문구류 사운드
- [ ] 입/손잡이 계열 추가 (상호작용 부여형 — 물리형과 다른 구현 축)
- [ ] 챕터1 12스테이지, 별점/개그 조건, 프랑켄슈타인 연출
- **DoD:** 테스터가 정답 외 괴물체로 클리어하는 장면 3회+ → **G1**

### Phase 2 — 스팀 페이지 & 데모 (세션 2회)
- [ ] 데모 = 챕터1 8스테이지 + 미니 샌드박스 (샌드박스가 데모 전환율 핵심)
- [ ] 캡슐 3안, 트레일러(괴물체 몽타주) → **G2 (1,000/4주)**

### Phase 3 — 프로덕션 (세션 10~14회)
- [ ] 4챕터 48스테이지, 눈 계열/파생 규칙, 부위 20종/몸통 15종
- [ ] 도감+스크린샷+GIF 내보내기, 도전과제 25개 (개그 괴물체 제작 조건)
- [ ] 물리 리그레션 봇: 전 스테이지 정답 시퀀스 자동 재생 × 물리 시드 10회 — 확률적 실패 검출
- **DoD:** 리그레션 통과율 100%, 진행불가 버그 리포트 0

### Phase 4 — 출시 (세션 2회)
- [ ] Next Fest → 출시. 커뮤니티 이벤트 "이달의 괴물체" (도감 스크린샷 콘테스트)
- [ ] 출시 후: 워크샵(커스텀 스테이지) 로드맵 — 이 장르는 UGC가 수명

## 6. Kill 체크
- Phase 0 물리 안정성 게이트 실패 → 즉시 Kill (버티면 개발 지옥 확정)
- 아트 부위 규격 작업량이 주당 계획 대비 2배 초과 지속 → 부위 변형 수 축소(계열당 2종) 후 재평가
- G1 창발 미발생(모두 정답 조합만 사용) → 스테이지 설계를 "정답 부위를 일부러 안 주는" 방향으로 리워크 1회, 재실패 시 Kill
