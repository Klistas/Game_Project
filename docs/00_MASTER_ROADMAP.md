> 작성일: 2026-07-07 | 대상: 솔로 개발 (Unity 6 / C#) | 도구: Claude Code 또는 Codex
> 전략: 저가(₩3,300~11,000) × 원 메커닉 × 클립 바이럴 × 스팀 우선

## 1. 이 문서 세트의 사용법

이 폴더에는 마스터 로드맵 1개 + 독립 기획서 3개가 있다.

| 파일 | 프로젝트 | 장르 | 목표 가격 | 예상 개발 기간 |
|---|---|---|---|---|
| `01_GDD_HwatuRogue.md` | 화투 로그 (가칭) | 덱빌딩 로그라이트 | ₩11,000 ($7.99) | 4~6개월 |
| `02_GDD_LuckyScratch.md` | 럭키 스크래치 (가칭) | 긁는 맛 방치형 | ₩4,400 ($2.99) | 6~10주 |
| `03_GDD_LastConvenience.md` | 새벽의 편의점 (가칭) | 규칙 기반 관찰 호러 | ₩5,500 ($3.99) | 8~12주 |

**진행 원칙:**
1. 동시에 하나만 진행한다. (권장 순서: 02 → 03 → 01. 작은 것으로 출시 근육부터 만든다)
2. 각 기획서의 Phase는 **Claude Code 세션 1~3회 분량**으로 설계되어 있다. Phase를 건너뛰지 않는다.
3. 각 Phase 끝에는 **완료 조건(DoD)** 과 **Kill 체크**가 있다. Kill 조건에 걸리면 미련 없이 Idea Pool로 되돌린다.
4. 프로젝트 루트에 해당 기획서를 `docs/GDD.md`로 복사해 두고, Claude Code에게 항상 이 문서를 기준으로 작업시킨다.

**Claude Code 세션 시작 프롬프트 템플릿:**
```
docs/GDD.md를 읽고 현재 Phase N의 태스크를 확인해.
이전 Phase까지의 코드 구조를 파악한 뒤, Phase N의 태스크를
하나씩 구현하고, 각 태스크 완료 시 docs/PROGRESS.md에 기록해.
GDD에 없는 기능은 임의로 추가하지 마.
```

## 2. 공통 파이프라인 (모든 프로젝트 적용)

```
Idea Pool → [G0] 프로토타입(1~2주) → [G1] 버티컬 슬라이스(2~4주)
→ [G2] 스팀 페이지 + 데모 → [G3] Next Fest/쇼케이스 → [G4] 프로덕션
→ [G5] 출시 → [G6] 출시 후 4주 운영
```

### 게이트별 Kill 기준 (kill-by-default)
- **G0 → G1:** 나 자신이 프로토타입을 "테스트가 아니라 재미로" 30분 이상 플레이하게 되는가? 아니오 → Kill.
- **G1 → G2:** 지인/학생 5명 이상 테스트에서 "돈 주고 사겠다" 3명 이상? 15초 클립을 봤을 때 뭐 하는 게임인지 즉시 이해되는가? 아니오 → Kill.
- **G2 → G3:** 스팀 페이지 오픈 4주 내 위시리스트 500+ (자연 유입 기준)? 아니오 → 훅/캡슐이미지 재설계 1회, 재실패 시 Kill.
- **G3 → G4:** 데모 이벤트 종료 시 위시리스트 총 3,000+ 그리고 데모 중앙값 플레이타임 15분+? 아니오 → 저가 소품으로 스코프 축소 후 조기 출시로 전환.

### 출시 최소 기준선
- 위시리스트 7,000+ (저가 게임 기준. 미달 시에도 출시는 하되 기대치 조정)
- 데모 피드백 반영 완료, 알려진 크래시 0
- **리뷰 90%+ 방어가 최우선.** 스코프를 줄여서라도 완성도를 지킨다. (90%+ = 알고리즘 플라이휠, 70%- = 침묵)

## 3. 공통 기술 스택 & 프로젝트 규약

- **엔진:** Unity 6 LTS, 2D URP (03만 3D 로우폴리 옵션)
- **아키텍처:** 준헌님 Console Game Framework 패턴 이식 — Singleton(GameManager류 최소화), EventBus, Observer, ScriptableObject 기반 데이터 주도 설계
- **데이터:** 밸런스 수치는 전부 ScriptableObject 또는 JSON. 코드에 매직넘버 금지 (Claude Code에게 명시할 것)
- **세이브:** JSON + `Application.persistentDataPath`, 버전 필드 포함
- **로컬라이즈:** KO/EN 필수 (텍스트는 처음부터 key 기반 테이블), Unity Localization 패키지
- **아트:** Ludo.ai 픽셀아트 파이프라인 재사용 + 필요 시 Aseprite 후보정
- **사운드:** freesound/Kenney + 필요 시 AI 생성(효과음), BGM은 라이선스 팩 구매
- **스팀:** Steamworks.NET, 도전과제 10~20개(방치형/로그라이트는 도전과제가 구매 요인), 클라우드 세이브
- **버전관리:** Git + GitHub private, Phase 단위 태그 (`v0.1-proto`, `v0.2-vs` ...)
