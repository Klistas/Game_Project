> 엔진: Unity 6, 2D URP | 16:9 + 스팀덱 검증 | 언어: KO/EN/JP/중간체 (텍스트량 적음 → 4개 국어 가능)

## 0. 원 센텐스 피치

**"마우스로 복권을 벅벅 긁어 당첨금을 모으고, 그 돈으로 더 비싼 복권과 자동 긁기 기계를 사서 복권 제국을 세우는 초저가 방치형."**

### 시장 근거
- 저가 복권 긁기 방치형이 최근 스팀 인디 흥행작으로 부상 — 검증된 최신 수요
- "긁는 촉각 쾌감(ASMR) + 당첨 순간의 도박적 도파민 + 방치형 숫자 증가" 삼중 훅
- 텍스트/아트/사운드 물량이 3개 기획 중 최소 → **첫 출시 근육 만들기에 최적**
- 당첨 순간 = 완벽한 15초 클립. 쇼츠/틱톡 바이럴 적합
- $2.99는 충동구매 가격대. 리뷰 관대함(가격 대비 기대치)의 수혜 최대

### 리스크
- 유사작 등장 속도가 빠른 장르 → **속도전.** 10주 내 출시가 곧 전략
- "도박 조장" 오해 → 실제 현금 요소 전무 명시, 스팀 태그/설명 신중히

## 1. 코어 루프

```
[액티브 루프] 복권 구매 → 마우스 드래그로 긁기 → 당첨 판정 연출 → 골드 획득
[성장 루프] 골드로 ①상위 티어 복권 해금 ②긁기 강화(긁는 면적/속도)
           ③자동화 기계 구매(초당 골드) ④행운 스탯(당첨률/배수)
[방치 루프] 오프라인 수익 (자동화 기계 기준, 최대 8시간)
[메타 루프] 프레스티지: "사업 확장" — 리셋 대가로 영구 배수 + 신규 도시 테마 해금
```

**세션 길이:** 액티브 10~20분 + 수시 확인. 총 콘텐츠 수명 15~25시간(프레스티지 5회 기준).

## 2. 시스템 설계

### 2.1 긁기 메커닉 (이 게임의 전부 — 손맛에 올인)
- 셰이더 기반 마스크 긁기: 복권 위 은박 레이어를 `RenderTexture` 마스크로 실시간 제거
- 긁을 때 은박 가루 파티클 + 사각사각 ASMR 사운드(속도에 따라 피치 변화) + 미세 햅틱 느낌의 화면 반응
- 85% 이상 긁으면 자동 완성 스냅 (편의성)
- **당첨 연출 3단계:** 소액(반짝) / 중액(골드 팡파레) / 잭팟(슬로모션 + 화면 전체 연출 + 통계 기록) — 잭팟 연출이 클립 재료

### 2.2 복권 티어 (콘텐츠 축)
| 티어 | 예시 | 가격 | 특징 |
|---|---|---|---|
| 1 | 편의점 즉석복권 | 10G | 튜토리얼 |
| 2 | 동물 복권 | 100G | 심볼 3매치 룰 추가 |
| 3 | 보물지도 복권 | 1K | 멀티 영역 긁기(순서 선택 전략) |
| 4 | 카지노 골드 | 50K | 배수 심볼, 리스크 룰 |
| 5 | 우주 복권 | 5M | 특수 기믹(연쇄 당첨) |
| 6+ | 프레스티지 해금 | — | 도시 테마별 변형 |
- 각 티어 = 룰 변형 1개씩 추가. 총 12종 목표 (MVP 5종)
- 당첨 테이블: `LotteryTierSO`에 (심볼, 확률, 배당) 배열 — **RTP(환급률)를 105~130%로 설계해 "긁을수록 반드시 성장"** (실제 도박과의 결정적 차이, 좌절 방지)

### 2.3 자동화 & 업그레이드
- 자동 긁기 기계 8종 (알바생 → 긁기 로봇 → 레이저 스캐너 → ...) 각 25레벨, 표준 방치형 지수 성장 (비용 ×1.15^n)
- 행운 스탯 트리: 당첨률/최소보장/잭팟확률/골드배수 4계열
- 오프라인 수익 = 자동화 DPS × 시간 × 0.5 (최대 8h, 업그레이드로 확장)

### 2.4 프레스티지 & 도전과제
- 프레스티지 화폐 "네잎클로버" → 영구 골드배수 + 신규 도시(테마 리스킨 + 신규 복권 1종)
- 도전과제 25개: "잭팟 첫 당첨", "누적 1억G", "복권 1만 장 긁기" 등 — **방치형 유저는 도전과제 헌터와 겹침, 구매 요인**
- 통계 화면(총 긁은 장수, 최대 잭팟, 세계 1위 잭팟 스팀 리더보드) — 커뮤니티 스크린샷 유도

## 3. 아트/사운드 방향

- **비주얼:** 밝고 뽀짝한 픽셀아트 or 벡터 플랫 (Ludo.ai 스타일 테스트 후 결정). 복권 디자인 자체가 아트의 핵심 — 티어별로 "긁고 싶게 생긴" 디자인
- 화면 구성 단순: 좌측 복권 진열대 / 중앙 긁기 존 / 우측 업그레이드 패널. UI가 곧 게임 화면
- **사운드가 체감 품질의 절반:** 긁는 소리(레이어 3종), 당첨 팡파레, 골드 코인 소리. 여기에 시간 투자
- 캡슐 이미지: 반쯤 긁힌 복권에서 "JACKPOT" 글자가 드러나는 순간

## 5. 개발 로드맵 (Claude Code Phase)

### Phase 0 — 셋업 (세션 1회)
- [ ] Unity 6 2D URP, Git, 폴더 규약, EventBus/SaveSystem 골격 이식
- [ ] `LotteryTierSO`, `AutomationSO`, `UpgradeSO` 스키마 + CSV 임포트 툴
- [ ] BigNumber 처리: `double` + 단위 포맷터(K/M/B/T... aa/ab) 유닛테스트
- **DoD:** 숫자 포맷터 테스트 통과, 더미 데이터 로드

### Phase 1 — 긁기 메커닉 (세션 2회) ★손맛에 전력
- [ ] RenderTexture 마스크 긁기 셰이더 + 브러시 반경/드래그 보간
- [ ] 긁힘 진행률 계산(GPU→CPU 비동기 리드백, 성능 주의) + 85% 자동완성
- [ ] 파티클/사운드 피치 연동, 당첨 판정 → 연출 3단계
- **DoD:** 아무 보상 없이도 긁는 행위 자체가 기분 좋은가 (5명 테스트) → **G0 게이트: "긁는 맛" 불합격이면 즉시 Kill**
- **Claude Code 지시:** "긁기 판정은 60fps 유지가 최우선. 리드백은 프레임당 1회 이하로 스로틀"

### Phase 2 — 경제 루프 (세션 2회)
- [ ] 골드/구매/업그레이드/자동화 틱 시스템 (틱은 UI와 분리된 순수 로직 + 테스트)
- [ ] 오프라인 수익 계산(재접속 정산 팝업)
- [ ] 밸런스 시트: 티어 도달 시간 곡선 스프레드시트 → CSV 반영
- **DoD:** 5종 복권으로 2시간 플레이 흐름이 끊기지 않음 → **G1 게이트 판정**

### Phase 3 — 스팀 페이지 & 데모 (세션 1~2회)
- [ ] Steamworks 연동, 데모(티어 3까지, 세이브 본편 이전)
- [ ] 캡슐 3안, 15초 잭팟 클립 3개 제작 → 쇼츠 업로드 시작
- **DoD:** 페이지 라이브 → **G2 트래킹.** 이 게임은 위시리스트 기준 완화(300/4주) — 저가 충동구매 장르 특성

### Phase 4 — 프로덕션 (세션 4~6회)
- [ ] 복권 12종, 자동화 8종, 프레스티지, 도시 3테마
- [ ] 도전과제 25개, 리더보드, 통계 화면, 클라우드 세이브
- [ ] 헤드리스 밸런스 봇: 최적 플레이 시뮬로 프레스티지 도달 시간 검증 (목표: 1차 프레스티지 3~4시간)
- **DoD:** 봇 시뮬 곡선이 설계 곡선 ±20% 이내

### Phase 5 — 출시 (세션 1~2회)
- [ ] Idle/Casual 계열 스팀 이벤트 신청, 스트리머 키(방치형/ASMR 채널 위주)
- [ ] 출시 후 2주 패치: 커뮤니티 요청 QoL + 신규 복권 1종 (리뷰 모멘텀용)
