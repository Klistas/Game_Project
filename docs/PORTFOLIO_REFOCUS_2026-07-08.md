# 포트폴리오 재초점 보고서 — 2026-07-08

## 결론

럭키 스크래치는 단독 상업 게임으로 계속 밀기보다 `스크래치 복권/랜덤 보상 모듈`로 보존한다. 복권을 긁는 조작은 촉감과 보상 연출로는 쓸모가 크지만, 그 자체만으로 긴 플레이 루프를 버티기에는 선택·숙련·상황 변화가 약하다.

새 단기 검증 1순위는 `스티커 월드`, 장기 메인 후보는 `화투 로그`로 둔다.

## 스티커 월드를 먼저 하는 이유

- 실패 비용이 낮다. 1-2주 안에 재미 여부를 볼 수 있다.
- 플레이스홀더 그래픽이어도 웃긴지 판단 가능하다.
- `태그 변경 → 규칙 해석 → 반응` 구조는 이름표 도시/포스터 타운에도 재사용된다.
- 외부 반응을 짧은 클립으로 확인할 수 있다.

## 화투 로그를 바로 풀개발하지 않는 이유

- 점수 엔진, 카드 UI, 부적, 시장, 밸런스가 동시에 필요하다.
- 아트가 좋아도 점수 폭발과 "한 판 더" 감각이 없으면 실패한다.
- 따라서 먼저 순수 점수 엔진 G0를 만들어야 한다.
