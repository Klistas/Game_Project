## 0. 원 센텐스 피치

**"'의자는 시민이다', '모자를 쓴 자만 투표할 수 있다' — 이상한 법을 제정해 마을을 조작하고, 고양이를 시장으로 당선시켜라."**

### 시장 근거
- Reigns(카드 통치), Frostpunk(법 제정)의 병맛 경량화 포지션 — "법 제정의 의도치 않은 결과"는 검증된 재미 축
- NPC 집단이 법을 곧이곧대로 해석해 사회 전체가 꼬이는 광경 = 리액션 유튜브 최적 소재
- 텍스트(법 조문/NPC 해석 대사) 중심이라 Claude API 생산 효율 최상

### 리스크와 대응 (이 기획의 급소)
- **시각 즉시성 부족:** 법은 추상 개념 → **모든 법은 제정 즉시 화면에 보이는 변화를 일으켜야 한다** (모자법 → NPC들이 즉시 모자 가게로 몰려감). "보이지 않는 법"은 채택 금지 — 법 카드 설계 제1원칙
- **시뮬 깊이의 유혹:** 진짜 사회 시뮬레이션 금지. NPC는 12종 원형(archetype)의 스크립트된 반응 집합. 창발은 "법 조합"에서만 나오게 한다
- 04/05 대비 프로토타입 비용이 크므로 프레임워크 검증 후 착수

## 1. 코어 루프

```
[일차 시작] 오늘의 목표 카드 공개 ("고양이를 당선시켜라 D-5")
→ 디오라마 마을 관찰 (NPC 12원형이 일과를 돎)
→ 법안 카드 3장 드로우 → 1장 제정 (또는 기존 법 폐지 = 1턴 소모)
→ 즉시: 마을 전체가 법대로 재해석되어 움직임 (시각 변화 필수)
→ 법 충돌/부작용 발생 → 다음 날 여론/경제 지표 변동
→ D-Day 이벤트(선거/축제/폭동) 판정 → 시나리오 클리어/실패
→ 신규 법 카드 해금 → 다음 시나리오
```

**구조:** 시나리오형 (5일 = 5턴 내 목표 달성). 시나리오 12개 + 무한 샌드박스 모드.
**세션:** 시나리오당 20~30분. **플레이타임:** 8~12시간.

## 2. 시스템 설계

### 2.1 법 카드 (출시 40종)
- 법 = `RuleSO`의 상위 개념: `(대상 태그) + (조건) → (의무/금지/지위 부여)`
- 카테고리: 신분법(의자는 시민이다), 경제법(감자는 화폐다), 복장법(모자=귀족), 행동법(뛰면 수상함), 시간법(정오엔 모두 춤춘다)
- **모든 법 카드에 "즉시 시각 반응" 필드 필수** — 없으면 카드 등록 자체가 안 되는 에디터 밸리데이션
- 법 충돌 매트릭스: 충돌 시 "재판 이벤트"(NPC 판사가 병맛 판결) — 충돌이 벌칙이 아니라 콘텐츠

### 2.2 NPC 사회 (원형 12종)
- 원형: 상인/경비/공무원/아이/노인/힙스터/부자/농부/판사/기자/고양이/의자(!)
- 각 원형 = 우선순위 큐(생계→법 준수→욕망). 법이 우선순위를 뒤틀면 행동이 바뀜
- 여론/경제/질서 3지표: 법의 부작용을 숫자+거리 풍경(쓰레기, 시위 피켓, 호황 장식)으로 동시 표현
- 기자 NPC: 매일 아침 병맛 신문 헤드라인 생성 (전날 사건 요약 — Claude API 배치 생성 템플릿) → 스크린샷 공유 유도 장치

### 2.3 시나리오 (12개)
- 선거/파산 위기/축제 유치/범죄와의 전쟁/외지인 유입/고양이 반란 등
- 각 시나리오 = 시작 상태 + 목표 + 사용 가능 법 풀 + 히든 개그 조건 (도전과제 연동)
- 샌드박스: 전 법 해금, 지표 붕괴까지 버티기 — 스트리머 모드

## 3. 아트/사운드 방향

- **비주얼:** 미니어처 디오라마 (보드게임 말 느낌의 납작 캐릭터, 종이 건물). 신 도입 시 카메라가 마을 전체를 한눈에 — "사회가 변하는 광경"이 한 화면에 담겨야 함
- 법 제정 연출: 거대한 도장이 하늘에서 내려와 "쾅" → 마을 전체 리플 이펙트 → NPC 일제 행동 변화. **이 5초가 게임의 아이덴티티 클립**
- 신문 UI(픽셀 신문)와 법전 UI(양피지)가 서사 전달의 전부 — 컷신 없음
- 캡슐: 투표함 앞에 줄 선 시민들 사이에 끼어 있는 의자와 고양이
