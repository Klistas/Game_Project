## 0. 원 센텐스 피치

**"'감자는 화폐입니다' 포스터 한 장으로 마을 경제를 무너뜨려라 — 포스터를 붙여 NPC의 상식을 조작하고, 믿음이 소문처럼 번지는 선동 퍼즐."**

### 시장 근거
- "NPC가 헛소리를 곧이곧대로 믿는다"는 밈 친화력 최상 — 5개 후보 중 클립 바이럴 잠재력 1~2위
- 확산 시뮬(믿음이 사람에서 사람으로 번짐)은 매 판 결과가 달라 리플레이/스트리머 소재 풍부
- 준헌님의 기존 기획 "조회수 때문에 세계가 망함"(여론 조작 테마 GDD)과 세계관/시스템 직결 — 기획 자산 재활용 가능

### 리스크와 대응 (이 기획의 급소)
- **"텍스트 게임처럼 보이면 죽는다":** 철칙 — **믿음 하나당 시각 변화 최소 2개 필수** (감자화폐 → NPC가 감자 들고 거래 + 상점 가격표가 감자 단위로 교체). 포스터 카드 등록 시 에디터 밸리데이션으로 강제
- 확산 시뮬 복잡도 → 진짜 전염 모델이 아니라 **구역 기반 단순 전파** (본 NPC → 같은 구역 대화 상대에게 확률 전파, 틱당 상한)

## 1. 코어 루프

```
[미션 시작] 목표 확인 ("부자 구역에 들어가라 D-3")
→ 마을 관찰: NPC들의 현재 '상식' 확인 (머리 위 말풍선 아이콘)
→ 포스터 제작: [주어 카드]+[술어 카드] 조합 ("모자를 쓴 자" + "귀족이다")
→ 부착 위치 선택 (광장/골목/학교/시장/시청 — 위치별 확산 특성)
→ 목격 NPC부터 믿음 전파 시작 (실시간 확산 시각화)
→ 믿은 NPC들의 행동 변화 → 경제/치안/유행 연쇄 반응
→ 목표 달성 or 마을 대혼란 (혼란도 게이지 초과 시 계엄 = 미션 실패)
→ 신규 카드/위치 해금
```

**구조:** 미션형 10개 + 자유 선동 샌드박스. **세션:** 미션당 15~25분. **플레이타임:** 7~10시간.

## 2. 시스템 설계

### 2.1 포스터 = 믿음 카드 조합 (자유 입력 금지)
- 주어 카드 16종: 고양이/모자 쓴 자/빨간 문/감자/시장님/비 오는 날/노란 물건...
- 술어 카드 16종: 위험하다/화폐다/귀족이다/문어다/행운을 준다/세금을 안 낸다/신성하다...
- 조합 = 16×16이지만 실제 반응은 **술어가 결정** (주어는 태그 타겟팅) → 구현량은 술어 16종 × 시각반응 2개 = 통제 가능
- 병맛 폴백: 정의 안 된 조합도 NPC가 "그런가...?" 하고 약한 믿음(행동 변화 없이 말풍선만) — 전부 반응하는 것처럼 느끼게

### 2.2 믿음 확산 모델 (단순하게, 보이게)
- NPC 상태: 모름 → 들어봄(회의적) → 믿음 → 광신 (단계별 행동 강도)
- 전파: 포스터 목격(강) / 믿는 NPC와 대화(중) / 소문 벽보 재생산(광신자가 직접 포스터 복제!) 
- **확산이 항상 화면에 보임:** 믿는 NPC 머리 위 아이콘 + 구역 물들기 이펙트(미니맵)
- 반박 시스템: 기자/학자 NPC가 "팩트체크 벽보"로 대항 → 플레이어는 그들을 먼저 다른 믿음으로 무력화하는 메타 전략
- 부착 위치 특성: 광장(광역 약전파)/골목(특정 집단 강전파)/학교(아이 먼저, 가정으로 2차 전파)/시장(경제 반응 가중)/시청(법제화 — 믿음이 규칙으로 굳음, 06과의 연결고리)

### 2.3 믿음 → 세계 반응 (술어 16종 각각)
예시:
- "X는 위험하다" → 경고 표지 스폰, NPC 우회 경로, X 주변 경비 배치
- "X는 화폐다" → 상점 가격표 교체, NPC가 X를 수집/거래, 기존 화폐 인플레
- "X는 귀족이다" → 경례, 출입 허가, X 가격 폭등(수요)
- "X는 신성하다" → 제단 스폰, 참배 행렬, X 훼손 시 폭동
- 경제/치안/유행 3지표 + 혼란도 게이지(과도 선동 시 계엄 실패 조건 — 난이도 축)

### 2.4 미션 & 서사
- 미션 10개: 부자 구역 잠입 → 라이벌 상점 파산 → 축제 유치 → 시장 탄핵 → 최종: 내가 퍼뜨린 모든 믿음이 충돌하는 대혼돈 수습
- 서사 톤: 주인공은 영세 "홍보사무소" 사장 — 선동의 달콤함과 대가를 겪는 풍자 아크, 엔딩 2종 (선동왕/참회)

## 3. 아트/사운드 방향

- **비주얼:** 빈티지 프로파간다 포스터 스타일 (실크스크린 질감, 2~3도 인쇄 느낌) — 포스터가 곧 아트 아이덴티티. 포스터 제작 UI 자체가 예쁜 인쇄기 미니게임
- 부착 순간: 풀칠 → 쓱쓱 → 광택. 확산은 잉크가 번지는 이펙트로 시각화 (테마 통일)
- NPC 믿음 리액션(감자 경배, 문어 시장 초상화 교체)이 클립 재료 — 리액션 애니메이션에 예산 집중
- 캡슐: "POTATO IS MONEY" 포스터 앞에 감자를 든 군중
