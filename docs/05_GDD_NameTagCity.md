# GDD — 이름표 도시 (가칭: LABEL CITY)

> 장르: 정체성 조작 퍼즐 어드벤처 | 가격: ₩8,800 / $5.99 | 기간: 3~5개월 | 플랫폼: Steam(PC)
> 엔진: Unity 6, 2D URP 탑다운 | 언어: KO/EN/JP
> 의존성: TagInteraction Framework (04와 공유)

---

## 0. 원 센텐스 피치

**"이 도시의 모든 것은 이름표로 판단된다 — 고양이에 '시장' 이름표를 붙이면 진짜 시장이 되는, 정체성 뒤바꾸기 퍼즐."**

### 04(스티커)와의 본질적 차이
- 스티커 = **성질**(무엇을 할 수 있는가)을 바꾼다 → 물리/행동 퍼즐
- 이름표 = **정체성**(무엇으로 취급되는가)을 바꾼다 → **사회적/제도적 퍼즐** (출입 권한, 소유권, 직위, 법적 지위)
- 유머 결이 다름: 스티커는 슬랩스틱, 이름표는 풍자. "세계가 겉모습(라벨)만 보고 판단한다"는 테마 자체가 메시지가 됨 → 리뷰/에세이형 유튜브 콘텐츠 유발

### 시장 근거
- "한 줄 설명의 강도"가 5개 후보 중 최상 — 캡슐+한 줄로 구매 결정되는 저가 시장에 최적
- Papers Please(서류가 곧 진실), Superliminal(인식이 곧 현실) 계열의 인지 비틀기 수요 검증됨
- 대사 물량이 많은 장르 → Claude API 배치 생성 파이프라인의 효율이 가장 큰 기획

### 리스크와 대응
- **자유 입력은 구현 불가** → 확정: **이름표 카드 수집제** (스테이지/월드에서 카드를 얻고, 떼면 회수)
- 04와 코어 중복 → Phase 0 토너먼트로 하나만 진행 (ADDENDUM 프로토콜)

## 1. 코어 루프

```
구역 진입 → 문제 확인 ("시청에 들어가 시장을 만나라")
→ 세계 관찰: 모든 엔티티 위에 이름표가 떠 있음
→ 보유 이름표 카드 확인 (예: [문][고양이][공무원][폭탄][화장실])
→ 이름표 떼기/바꿔붙이기 (떼인 이름표는 인벤토리로)
→ NPC/시스템이 '이름표 기준으로' 재판단 → 현실이 꼬임
→ 연쇄: 잘못된 판단이 새 문제/기회를 만듦
→ 목표 달성 → 신규 이름표 해금 + 도시 평판 변화
```

**구조:** 스테이지형이 아니라 **허브 도시 + 6구역** 세미오픈. 구역 안에서는 자유 실험.
**플레이타임:** 7~10시간, 엔딩 3종 (이름표 사용 성향에 따라: 질서/혼돈/진실 엔딩).

## 2. 시스템 설계

### 2.1 이름표 시스템
- 모든 `Entity`는 `TrueTag`(실제 성질)와 `LabelTag`(이름표)를 분리 보유
- **세계의 판단 주체별로 무엇을 보는지가 다름** — 이것이 퍼즐의 깊이:
  - NPC/경비/제도(문, 은행, 투표) → `LabelTag`만 본다
  - 물리 법칙 → `TrueTag`만 본다 (벽에 '문' 붙여도 NPC는 열려고 하지만 실제로는 안 열림 → NPC가 벽에 쿵 = 개그이자 단서)
  - 동물/아이/광인 NPC → `TrueTag`를 본다 (진실을 아는 존재들 — 서사 장치)
- 이름표 카드 출시 목표 24종: 신분(공무원/경찰/시장/귀족/범죄자), 사물(문/폭탄/화장실/은행/쓰레기), 개념(무료/금지/신성함/전염병) 등
- 같은 이름표가 2개 존재하면 **시스템 충돌 이벤트** (시장이 2명 → 시청 내전) — 고급 퍼즐 재료

### 2.2 NPC 판단 AI
- NPC 직업별 "관심 이름표 목록" + 반응 프리미티브 (통과 허가, 체포, 경배, 거래, 대피, 신고)
- 신고/소문 시스템: 이상 행동 목격 시 경비 호출 — 잠입 텐션 부여 (라이트하게)
- 대사: 상황 태그 × 직업 × 이름표 조합의 반응 대사 뱅크 (Claude API 배치 생성 → 검수 → CSV, 목표 1,500라인)

### 2.3 구역 구성 (허브 + 6구역)
1. 튜토리얼 골목 (이름표 개념 학습)
2. 시장통 (경제: '무료'/'화폐' 이름표 장난)
3. 시청 (권력: '공무원'/'시장')
4. 은행 (보안: '금고'→'화장실' 류)
5. 극장가 (정체성 테마 서사 심화)
6. 재판소 (최종: 모든 이름표 규칙이 충돌하는 대혼돈)
- 구역별 메인 목표 1 + 서브 목표 3~4 (서브가 신규 카드 보상)

### 2.4 평판/엔딩
- 이름표 조작이 들킬 때마다 "도시 의심 게이지" 상승 → NPC들이 이름표를 재확인하기 시작 (동적 난이도)
- 엔딩 분기: 조작 최소(질서) / 대혼돈 달성(혼돈) / 진실을 보는 NPC들과 연대(진실)

## 3. 아트/사운드 방향

- **비주얼:** 종이/판지 공작 스타일 — 세계 자체가 "라벨이 붙은 공작물"이라는 테마 일치. 이름표는 항상 머리 위에 물리적 택으로 표시 (게임의 아이콘이자 UI)
- 이름표 교체 순간: 택이 팔랑 떨어지고 새 택이 도장 찍히듯 "쾅" — 손맛 연출
- NPC가 오판하는 순간의 리액션 애니메이션(경례, 절, 비명)에 아트 예산 집중 — 클립 재료
- 캡슐: 고양이 머리 위 '시장(MAYOR)' 이름표 + 절하는 시민들
