# 스티커 월드 G0 개발 계획 — 2026-07-08

## 목표

플레이스홀더 그래픽만으로도 "스티커를 붙였더니 세계가 웃기게 반응한다"는 핵심 재미가 보이는지 검증한다.

G0는 완성 게임이 아니다. 목적은 15초 클립으로 이해되는 코미디와 창발 가능성을 확인하는 것이다.

## 한 줄 게임 개요

사물과 NPC에 `졸림`, `폭발`, `왕`, `개`, `작음` 같은 속성 스티커를 붙여 스테이지 목표를 해결하는 병맛 퍼즐 샌드박스.

## 하나의 게임 루프

```text
스테이지 입장
→ 목표 확인
→ 오브젝트/NPC 관찰
→ 제한된 스티커를 드래그해서 부착
→ 태그가 바뀜
→ 규칙 해석기가 반응을 실행
→ 목표 달성 또는 대참사
→ 즉시 리트라이/다음 스테이지
```

## G0 플레이 예시

목표: 은행 금고에 들어가라.

사용 가능 스티커:
- `졸림` 1장
- `개` 1장
- `작음` 1장

가능한 해법:
- CCTV에 `졸림`을 붙여 감시를 끈다.
- 고양이에 `개`를 붙여 짖게 만들고 경비를 유인한다.
- 플레이어에게 `작음`을 붙여 금고 문 아래 틈으로 들어간다.

좋은 G0는 이 해법이 정답처럼만 보이지 않고, 테스트 플레이어가 "그럼 의자에 개를 붙이면?" 같은 실험을 자연스럽게 하게 만들어야 한다.

## G0 스코프

| 항목 | 수량 | 기준 |
|---|---:|---|
| 스티커 | 5종 | 졸림, 폭발, 왕, 개, 작음 |
| 오브젝트/NPC | 8종 | 플레이어, 경비원, CCTV, 문, 벽, 금고, 고양이, 의자 |
| 스테이지 | 3-5개 | 은행 테마만 |
| 반응 프리미티브 | 10-15종 | 수면, 절전, 폭발, 도주, 유인, 절하기, 크기변경 등 |
| 규칙 | 20개 내외 | 데이터 기반 |
| 아트 | 플레이스홀더 | 도형/색상/라벨만 사용 |

## 필요한 기능

| 기능 | 목적 |
|---|---|
| TagSO | `Human`, `Guard`, `Machine`, `Sleepy`, `Royal` 같은 태그 정의 |
| StickerSO | 스티커가 추가/제거하는 태그 정의 |
| TagRuleSO | 태그 조건과 이벤트가 맞을 때 실행할 반응 정의 |
| RuleResolver | 현재 태그와 이벤트를 보고 실행할 규칙 선택 |
| ReactionLibrary | 실제 반응 프리미티브 실행 위치 |
| TaggedEntity | 씬 오브젝트가 현재 태그를 보유 |
| Sticker drag/drop | 플레이어가 스티커를 붙이는 핵심 조작 |
| Goal checker | 목표 달성 여부 판정 |
| Stage reset | 실패/대참사 후 즉시 재시도 |
| Debug overlay | 엔티티의 현재 태그와 매칭 규칙 표시 |

## 필요한 에셋

G0에서는 외부 에셋을 쓰지 않는다.

필요한 placeholder:
- 스티커 아이콘 5종: 색상 카드 + 한글 라벨
- 오브젝트 8종: 단순 도형 + 라벨
- 은행 배경: 바닥/벽/금고/감시 영역 도형
- 반응 이펙트: 잠듦 Z, 폭발 원, 절하기 화살표, 느낌표, 물음표
- 사운드: 나중에 프로시저럴 또는 Common Kit 훅으로 연결

출시 후보가 되면 필요한 최종 에셋:
- 손그림 낙서 스타일 스티커 12종
- 오브젝트/NPC 25종
- 챕터 배경 5종
- 반응 애니메이션 30종 이상
- 부착 사운드, 폭발/수면/도주/절하기 효과음

## 데이터 설계 원칙

- 스티커×오브젝트 개별 코드 금지.
- `태그 조건 + 이벤트 → 반응 프리미티브` 구조로만 상호작용을 만든다.
- 매칭 안 되는 조합도 무반응으로 방치하지 않고 물음표/갸우뚱 같은 범용 폴백을 보여준다.
- 신규 스티커/규칙은 CSV 또는 SO 데이터 추가로 확장 가능해야 한다.

## G0 완료 조건

- 태그/규칙/반응 엔진 EditMode 테스트 통과
- 플레이어가 스티커를 드래그해 대상에 붙일 수 있음
- 최소 3개 스테이지가 클리어 가능
- 최소 2개 이상의 의도 밖 해법이 발생
- 플레이스홀더 클립 1개가 말 없이 이해됨
- 콘솔 에러 0

## Kill 기준

- 플레이스홀더 상태에서 웃긴 반응이 전혀 나오지 않음
- 모든 퍼즐이 단일 정답 루트로만 풀림
- 태그 조합이 늘어날수록 코드 수정이 필요해짐
- 15초 클립을 봐도 무엇이 재미인지 설명이 필요함
