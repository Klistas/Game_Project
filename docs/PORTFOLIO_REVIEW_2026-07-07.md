## 3. 점수 근거

### 1위 — 럭키 스크래치 (34점)
- **완주 9:** 코어(긁기)와 경제 루프가 **이미 구현 완료**. 남은 건 콘텐츠 물량(복권 7종 추가)+폴리시+Steamworks. GDD 기간 6~10주 중 실질 절반 소화. 3개 시장검증형 중 스코프 최소
- **마케팅 8:** 잭팟 순간 = 완벽한 15초 클립, 긁는 소리 = ASMR 쇼츠 문법. 감점은 유사작 등장 속도가 빠른 장르라는 점 (GDD도 "속도전" 명시 — 오히려 빨리 낼 이유)
- **수익화 7:** 최근 스팀에서 검증된 최신 수요, $2.99 충동구매 가격, 리뷰 관대함. 상방은 낮은 편(수천만 원대 기대치)이지만 **첫 출시 근육 + 다음 작 크로스 위시리스트 기반**이라는 전략 가치가 큼
- **에셋 10:** 복권 = 정형화된 2D 카드 1장. 티어 추가가 CSV 한 줄 + 이미지 1장. AI 이미지 생성과 궁합 최고. 사운드도 긁기/팡파레 소수면 충분

### 2위 — 새벽의 편의점 (30점)
- **완주 7:** 원 메커닉 소품(8~12주), 수칙×손님 조합이 데이터 주도라 물량 생산 쉬움. 감점: 호러 "무드" 연출은 수치가 아니라 감각의 영역 — 사운드 디자인 실패 시 게임 전체가 죽음
- **마케팅 9:** 판별 실패 순간의 비명 = 스트리머 리액션 콘텐츠 그 자체(무료 마케팅). K-편의점 괴담은 글로벌에 신선. Scream Fest 등 장르 이벤트 존재
- **수익화 8:** 벅샷 룰렛이 증명한 단편 저가 호러 수요, $3.99. 스트리머 한 명 터지면 상방이 열리는 구조
- **에셋 6:** 손님 스프라이트 변형 물량 + 배경 + 사운드 레이어. 데이터 주도로 통제 가능하나 02보다 확실히 무겁고, "무서워 보여야 함"이라는 품질 바가 있음

### 3위 — 화투 로그 (29점)
- **완주 5:** 4~6개월, 밸런스 스코프가 3개 중 최대. GDD 스스로 "02·03 출시 경험 후 착수"를 권장. 첫 타석으로는 위험
- **마케팅 7:** 발라트로 계열이라는 관심 자산 + 화투 비주얼의 캡슐 차별화. 다만 클립의 순간 임팩트는 방치형/호러보다 약함 (콤보 터지는 순간으로 커버 가능)
- **수익화 9:** 포트폴리오 중 기대 매출 최고. 발라트로($1억+)·Gambonanza(2주 20만 장)로 연속 검증된 공식, $7.99 가격 방어 가능, 도전과제 헌터·리플레이 수요
- **에셋 8:** 화투 48장 + 부적/유물 아이콘 — 규격이 정형화된 2D라 AI 파이프라인 적합. 연출 이펙트가 추가 비용

### 4~5위 — 스티커 월드(28) / 이름표 도시(26) / 포스터 타운(26)
- 공통 강점: **클립 바이럴 최상급** (병맛 순간이 곧 콘텐츠). 공통 약점: ①TagInteraction Framework 선행 개발 2주 필요 ②직접 비교 가능한 최근 매출 검증 사례가 약함(ADDENDUM 명시) ③창발 QA 부담 → 완주 점수가 낮음
- 스티커(04)가 셋 중 1순위인 이유: "붙인다=그렇게 된다" 3초 이해, 스테이지형이라 스코프 통제 용이
- 포스터 타운(07)은 확산 시뮬 복잡도로 완주 4점이지만, **ViewCountRuinedWorld의 세계관/기획 자산을 재활용 가능**(GDD 명시)한 유일한 신규 기획
- 운용 원칙(ADDENDUM): 04 vs 05는 프레임워크 위에 각 1주 프로토 토너먼트로 하나만 진행

### 하위권 근거
- **오려 붙이기(08, 22점):** 클립 잠재력은 최상(마케팅 9)이나 물리 QA 지옥 + 부위 규격 에셋 제작 부담(에셋 3)으로 배치 내 최후순위 지정이 타당
- **ViewCountRuinedWorld(21점):** 구현은 가장 진척됐지만 상업 기준으로는 약함 — 추리/텍스트형이라 15초 클립 즉시성이 낮고(스코어카드의 kill flag "재미가 화면 액션이 아니라 텍스트"에 걸릴 위험), 직접 비교 매출 사례 부재. **단, 자산 폐기가 아니라 07 포스터 타운의 세계관·기획으로 승계하는 경로가 있음**
- **법 만들기(06, 21점):** 시각 즉시성 부족이 급소. 04/05 성공 후 2호기 — 기존 보류 판단 유지가 맞음
- **EveryoneInnocent(20)/BodyRebels(18)/IntendedFeature(17):** 6/20 내부 랭킹 이후 신호가 약하거나(BR 게이트 0/10) 검증 미실시(IF). 유지보수 비용만 안 들게 WARM_STANDBY 유지

## 4. 충돌 사항 및 권장 결론

**⚠ 문서 충돌:** `_Commercial/PrototypePortfolioDecision.md`(7/7 갱신)는 ViewCountRuinedWorld를 Primary로 지정하지만, 같은 날 추가된 `docs/00_MASTER_ROADMAP.md`는 02→03→01 전략을 제시. 두 트랙을 병행할 리소스는 없으므로 **하나를 명시적으로 선택해야 함.**

**권장안 (점수 기준):**
```
지금: 럭키 스크래치 완주 (남은 6~8주) ← 이미 절반 구현, 최단 출시
출시 후: 새벽의 편의점 착수 + TagInteraction Framework 병행(2주)
→ 스티커 vs 이름표 토너먼트 → 승자 진행
화투 로그: 출시 경험 2회 축적 후 메인 프로젝트로
ViewCount: 개발 중단하되 세계관·기획을 포스터 타운 재료로 보존
```

수익 기대만 보면 화투 로그가 1위지만, 출시 경험 0회 상태에서 4~6개월짜리에 올인하는 것은 로드맵의 kill-by-default 원칙과 상충. **작은 것부터 출시 근육을 만드는 현재 로드맵이 점수상으로도 타당함.**
