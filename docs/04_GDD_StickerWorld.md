## 0. 원 센텐스 피치

**"사물에 '졸림', '폭발', '왕' 같은 속성 스티커를 붙이면 진짜 그렇게 되는 병맛 퍼즐 — 의자에 '개' 스티커를 붙여 경비를 유인하라."**

### 시장 근거
- Baba Is You(규칙 조작 퍼즐)의 대중화 버전 포지션. Baba는 추상적이라 진입장벽이 있었지만, 스티커는 "붙인다 = 그렇게 된다"로 3초 이해
- "고양이에 왕 스티커 → 모두가 절함" 같은 순간이 그대로 15초 클립 = 마케팅 비용 0의 확산 구조
- 스테이지형이라 스코프 통제 용이, DLC/워크샵 확장 여지 큼

### 리스크와 대응
- **조합 폭발:** 스티커×오브젝트 개별 구현 금지. 태그×반응 프리미티브로 환원 (ADDENDUM 참조)
- **퍼즐이 아니라 노가다가 될 위험:** 스테이지마다 정답 2개 + 창발 해법 N개 구조. 정답이 하나뿐이면 병맛이 죽는다

## 1. 코어 루프

```
스테이지 입장 → 목표 확인 ("금고에 들어가라")
→ 배치된 오브젝트/NPC 관찰
→ 인벤토리 스티커(스테이지당 3~5종, 각 1~2장 제한) 부착
→ 태그 변경 → 세계가 반응 (연쇄 상호작용)
→ 목표 달성 or 대참사(리트라이 즉시)
→ 별점(사용 스티커 수/시간) + 신규 스티커 해금
→ 다음 스테이지
```

**세션:** 스테이지당 3~8분. 챕터(10스테이지) 단위 신규 스티커 도입.
**플레이타임:** 출시 기준 6~9시간 (60스테이지 + 챌린지 15).

## 2. 시스템 설계

### 2.1 스티커 (출시 12종 — 절대 초과 금지)
| 스티커 | 태그 | 대표 반응 |
|---|---|---|
| 졸림 | Sleepy | 생물: 잠듦 / 기계: 절전(꺼짐) |
| 폭발 | Explosive | 충격 시 폭발, 벽 파괴 |
| 작음 | Tiny | 크기 30%, 틈새 통과, 감시범위 축소 |
| 큼 | Giant | 크기 250%, 통로 막음, 무거움 |
| 왕 | Royal | 주변 NPC가 절함/복종 |
| 개 | Dog | 짖음(소리 유인), 뼈다귀 추적 |
| 자석 | Magnetic | 금속 오브젝트 끌어당김 |
| 무서움 | Scary | NPC 도주 |
| 사랑 | Lovely | NPC 추종/호위 |
| 미끌 | Slippery | 밟으면 미끄러짐, 잡을 수 없음 |
| 시끄러움 | Loud | 지속 소음 발생(유인/은폐) |
| 유령 | Ghost | 벽 통과, 상호작용 불가 |

- 스티커는 떼서 재사용 가능 (떼면 잔여 접착 자국 연출 — 병맛 디테일)
- 한 오브젝트에 최대 2장 → 조합 태그 (예: 개+큼 = 대형견 공포 유발 = Scary 자동 부여 같은 **파생 규칙** 소수만 수제작)

### 2.2 오브젝트/NPC (출시 25종)
- 공통 `Entity` + 기본 태그 (예: 경비원 = `Human, Guard, CanSleep`, CCTV = `Machine, Watcher`, 고양이 = `Animal, Cute`)
- NPC AI: 유틸리티 기반 단순 상태머신 (순찰/조사/도주/복종/추종/수면) — 반응 프리미티브가 상태 전이를 트리거

### 2.3 규칙 해석기
- `RuleSO`: `(태그 조건) + (이벤트) → (반응 프리미티브 + 파라미터)` 전부 데이터
- 목표 규칙 수: 코어 60개 + 파생/개그 40개. 매칭 실패 시 병맛 폴백(물음표, NPC 갸우뚱 대사)
- 대사 뱅크: 상황 태그별 3~5개 변형 — Claude API로 배치 생성 후 검수하여 CSV로 굽기

### 2.4 스테이지 & 진행
- 5챕터 × 12스테이지 = 60 + 챌린지 15 (스티커 1장 클리어 등)
- 챕터 테마: 은행 → 미술관 → 우주정거장 → 유령 저택 → 시상식(최종)
- 스테이지 에디터를 **개발 도구 겸 출시 후 워크샵 후보**로 처음부터 데이터 기반 제작 (JSON 레벨 포맷)
- 별점 3 조건 공개 → 리플레이 유도. 힌트 시스템(30초 후 "이 오브젝트를 봐" 수준)

## 3. 아트/사운드 방향

- **비주얼:** 손그림 낙서 스타일 (마커/크레용 질감) — 병맛 톤과 일치, Ludo.ai + 후보정으로 생산성 확보. 스티커는 반짝이는 홀로그램 테두리로 "붙이고 싶게"
- 부착 순간 연출: 쫀득한 스퀴시 애니메이션 + "쩍!" 사운드 — **이 손맛이 게임의 절반**
- 카메라: 2D 탑다운(제작 효율) 권장. 대참사 순간 자동 슬로모션+줌 (클립 자동 생성기 역할)
- 캡슐: 심각한 표정의 경비원 이마에 '졸림' 스티커가 붙는 순간
