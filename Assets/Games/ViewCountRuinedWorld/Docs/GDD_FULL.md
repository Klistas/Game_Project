# 조회수 때문에 세계가 망함 - 전체 게임 기획서 + Codex 실행 매핑

# A. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 가제 | 조회수 때문에 세계가 망함 |
| 장르 | 싱글 사회 시뮬레이션 + 로그라이크 + 카드 조합 + 병맛 전략 게임 |
| 시점 | 쿼터뷰 미니 마을 시뮬레이션 |
| 플레이 시간 | 1런 15~25분, 전체 해금 6~10시간 목표 |
| 대상 플랫폼 | Steam PC 우선 |
| 목표 유저 | 병맛 시뮬레이션, 덱빌딩/로그라이크, 스트리머 클립형 게임을 좋아하는 유저 |
| 한 줄 피치 | 가짜뉴스 쇼츠를 올렸더니 NPC들이 믿기 시작하고, 믿는 사람이 많아질수록 그 소문이 마을 법칙이 되는 병맛 사회 시뮬 로그라이크 |
| 핵심 재미 | 말도 안 되는 소문을 전략적으로 퍼뜨려 원하는 엔딩으로 마을을 조작하는 재미 |
| 차별점 | 카드 조합 결과가 전투력이 아니라 사회 규칙을 바꾼다 |
| 시장성 | 쇼츠/클립 시대에 한 장면 설명만으로 이해되는 훅이 강하다 |

## 핵심 재미
- 내가 만든 소문이 실제 NPC 행동을 바꾼다.
- 행동 변화가 쌓여 마을 규칙이 된다.
- 소문끼리 충돌해 병맛 판례가 생긴다.
- 성공도 실패도 짧고 공유하기 쉬운 장면으로 끝난다.

# B. 핵심 컨셉 설명

## 플레이어가 하는 일
플레이어는 악성 루머 스트리머다. 매일 카드 3장을 조합해 쇼츠를 만들고, 조회수와 믿음 확산을 이용해 마을 상태를 조작한다. 목표는 7일 안에 선택한 병맛 엔딩 조건을 달성하는 것이다.

## “소문이 세계 법칙이 된다” 구조
1. 소문이 쇼츠로 업로드된다.
2. NPC 집단이 성향에 따라 소문을 의심하거나 믿는다.
3. 믿음 단계가 `의심 -> 유행 -> 상식 -> 법칙`으로 상승한다.
4. 법칙 단계가 되면 마을 오브젝트, NPC 행동, 기관 규칙이 실제로 바뀐다.
5. 여러 법칙이 동시에 존재하면 충돌 이벤트가 발생한다.

## 왜 병맛인가
- 소재가 완전히 가상의 마을과 물건 중심이다.
- 바나나가 신분증이 되고, 고양이가 후보가 되고, 시장님이 문어 의심을 받는다.
- 논리는 말이 안 되지만 시스템은 일관적이라 플레이어가 전략적으로 악용할 수 있다.

## 왜 클립성이 있는가
- “바나나 없는 고양이는 투표 가능한가?”처럼 한 문장만으로 웃긴 충돌이 생긴다.
- 업로드, 조회수 폭발, 법칙화, 실패 엔딩이 모두 짧은 영상 단위로 끊긴다.
- 하루 종료 리포트가 방송 요약 자막처럼 작동한다.

## 왜 1인 개발에 맞는가
- 2D 고정 마을과 데이터 테이블 중심이다.
- NPC는 개별 AI가 아니라 타입별 반응 테이블로 제어한다.
- 새로운 콘텐츠는 카드/태그/문구/아이콘 추가로 확장한다.
- 멀티, 자유 입력, 3D 오픈월드는 MVP에서 제외한다.

## AI 활용 원칙
AI는 문장 표현, 댓글, 헤드라인, 엔딩 문구 보조에만 사용한다. 실제 규칙, 밸런스, NPC 행동, 엔딩 조건은 반드시 고정 데이터로 통제한다.

| 단계 | 플레이어 행동 | 시스템 계산 | 화면 정보 | 재미 포인트 | 성공/실패 조건 |
|---|---|---|---|---|---|

| 3. 마을 상태 확인 | 구역/NPC/상태값 관찰 | 상태값/활성 소문 표시 | 마을 지도와 상태 패널 | 전략적 판단 | 위험 수치 확인 |
| 4. 소문 카드 획득 | 카드 드로우/보정 선택 | 희귀도/해금/목표 보정 | 카드 손패 | 좋은 조합 찾기 | 카드 3축 확보 |
| 5. 카드 3장 조합 | 대상+주장+조건 선택 | RumorData 생성 | 예상 제목, 수치, 반응 집단 | 말도 안 되는 조합의 웃음 | 업로드 가능 |
| 6. 쇼츠 업로드 | 제목/썸네일 톤 선택 | 조회수/공유/신고 계산 | 스마트폰 UI, 댓글 | 숫자 상승 쾌감 | 업로드 완료 |
| 7. NPC 반응 | 피드와 말풍선 관찰 | 집단별 반응 생성 | NPC 댓글/행동 | 진짜 믿는 순간 | 믿음 점수 변화 |
| 8. 믿음 확산 | 확산 지도 확인 | 반복 노출, 태그 선호, 분위기 계산 | 구역별 단계 색상 | 퍼지는 맛 | 단계 상승 |
| 9. 규칙 변화 | 새 법칙 효과 확인 | 법칙 단계 효과 적용 | 안내판/검문/품절 | 세계가 바뀌는 핵심 | 법칙 적용 |
| 10. 부작용 | 대응 여부 선택 | 태그 기반 부작용 적용 | 경고 팝업, 리포트 | 내가 만든 재앙 | 피해 관리 |
| 11. 기관/라이벌 반응 | 팩트체크/경찰/기자 대응 | 개입도/신고/반박 계산 | 뉴스 배너 | 방해를 역이용 | 압박 관리 |
| 12. 다음 날 | 리포트 보고 다음 전략 선택 | 해금/피로도/상태 지속 | 하루 종료 리포트 | 원인과 결과 학습 | 다음 날 진입 |
| 13. 엔딩 판정 | 7일 내 조건 달성 시 성공 | EndingEvaluator 실행 | 성공/실패 컷신 | 짧은 완결 보상 | 런 종료 |

# D. 시작부터 끝까지의 게임 프로세스

## 1. 타이틀 화면
- 마을은 평화로워 보이지만 배경에서 이미 작은 이상 현상이 보인다.
- 버튼: 새 게임, 이어하기, 엔딩 도감, 부작용 도감, 설정, 종료.

## 2. 새 게임 시작
- 플레이어는 3개 MVP 엔딩 중 하나를 선택한다.
- 첫 런은 고양이 대통령 또는 바나나 신분증 튜토리얼을 추천한다.

## 3. 튜토리얼
- 첫 카드 조합은 `[바나나]+[신분증이다]+[없으면 체포]`로 고정한다.
- 업로드 후 주민이 바나나를 들고 다니고, 경찰이 장난 검문을 시작한다.
- 플레이어는 “소문이 행동을 바꾼다”를 즉시 본다.

## 4. 중반부 전략 선택
- 엔딩에 맞는 핵심 태그를 밀지, 부작용을 관리할지 선택한다.
- 예: 고양이 엔딩은 고양이 지지율을 올리면서 시장 신뢰도를 낮춘다.

## 5. 후반부 통제 불능
- 5~6일차부터 팩트체크, 반대 소문, 기관 개입, 충돌 이벤트가 동시에 발생한다.
- 플레이어는 기존 소문을 지킬지, 더 큰 소문으로 덮을지 결정한다.

## 6. 엔딩 조건 달성/실패
- 7일 전 조건을 달성하면 즉시 성공 엔딩.
- 7일 종료 시 조건이 부족하면 실패 엔딩.
- 실패해도 “최고 개소문”, “가장 큰 부작용”, “망한 이유”가 리포트로 남는다.

## 7. 결과 정산과 다음 런
- 새 카드, 썸네일 톤, 부작용 도감, 엔딩 힌트가 해금된다.
- 다음 런에서는 다른 엔딩과 조합을 시도하게 한다.

# F. 소문 카드 시스템

## 카드 타입
| 타입 | 역할 | 예시 | 희귀도 기준 | 해금 방식 | 밸런스 기준 |
|---|---|---|---|---|---|
| 대상 카드 | 소문의 주체, 영향 구역/NPC 결정 | 고양이, 바나나, 시장님, 경찰 | 흔한 생활물 common, 기관/특수 rare | 엔딩 진행, 도감, 실패 보상 | 엔딩 핵심 대상은 초반부터 접근 가능 |
| 주장 카드 | 소문의 의미와 핵심 태그 결정 | 신분증이다, 문어다, 돈을 부른다 | 직접 승리 기여 claim은 uncommon 이상 | 엔딩별 1회 실패 후 보정 | 자극도와 신뢰도의 상충 필요 |
| 조건/효과 카드 | 발동 조건, 리스크, 부작용 결정 | 없으면 체포, 밤에만, 선거에 영향 | 강한 법/경제 효과는 rare | 부작용 경험, 특정 엔딩 달성 | 고효율일수록 신고/피로도 상승 |

## MVP 카드 수
- 대상 카드 18장.
- 주장 카드 18장.
- 조건/효과 카드 18장.
- 총 54장.

## 카드 데이터 필수 필드
`id`, `type`, `name_ko`, `rarity`, `tags`, `base_sensational`, `base_credibility`, `target_groups`, `unlock`.

# G. 소문 생성 예시 20개

## G-1. [바나나]+[신분증이다]+[없으면 체포]

- 카드 조합: [바나나]+[신분증이다]+[없으면 체포]
- 생성된 쇼츠 제목: “충격! 이제 바나나 없으면 신분 확인 불가?”
- NPC 초기 반응: 주민 몇 명이 바나나를 지갑처럼 들고 다닌다.
- 확산 1단계: 편의점 바나나 매출 증가
- 확산 2단계: 경찰이 장난삼아 바나나 검문 시작
- 확산 3단계: 관공서 직원이 바나나 확인 요구
- 법칙화 결과: 바나나 없으면 관공서 출입 불가
- 부작용: 바나나 가격 폭등, 암시장
- 어떤 엔딩에 유리한지: 바나나 정부 수립

## G-2. [고양이]+[시장보다 낫다]+[선거에 영향을 준다]

- 카드 조합: [고양이]+[시장보다 낫다]+[선거에 영향을 준다]
- 생성된 쇼츠 제목: “시장님보다 말 적은 고양이가 더 낫다는 여론”
- NPC 초기 반응: 학생들이 고양이 후보 밈을 만든다.
- 확산 1단계: 광장에 고양이 포스터
- 확산 2단계: 기자가 고양이 지지율 보도
- 확산 3단계: 공무원이 고양이 발도장 양식 검토
- 법칙화 결과: 고양이 후보 등록 인정
- 부작용: 고양이 간식 매수 논란
- 어떤 엔딩에 유리한지: 고양이 대통령 당선

## G-3. [시장님]+[문어다]+[비 오는 날만]

- 카드 조합: [시장님]+[문어다]+[비 오는 날만]
- 생성된 쇼츠 제목: “비 오는 날 시장님의 팔이 늘어난다?”
- NPC 초기 반응: 기자가 우산 쓴 시장님을 관찰한다.
- 확산 1단계: 비 오는 날 광장에 주민 몰림
- 확산 2단계: 시장실 창문에 문어 낙서
- 확산 3단계: 기상 예보가 정치 뉴스화
- 법칙화 결과: 비 오는 날 시장님은 문어로 간주
- 부작용: 우산 품절, 팩트체크 압박
- 어떤 엔딩에 유리한지: 시장님 문어화

## G-4. [편의점]+[세금을 낮춘다]+[믿으면 돈을 번다]

- 카드 조합: [편의점]+[세금을 낮춘다]+[믿으면 돈을 번다]
- 생성된 쇼츠 제목: “편의점 영수증이 세금을 낮춘다?”
- NPC 초기 반응: 상인들이 영수증을 부적으로 붙인다.
- 확산 1단계: 영수증 수집 유행
- 확산 2단계: 편의점 줄 폭증
- 확산 3단계: 공무원이 영수증 민원 창구 설치
- 법칙화 결과: 영수증 제출이 세금 상담 조건

# H. 믿음 확산 시스템

| 단계 | 믿음 수치 | NPC 행동 변화 | UI 표시 | 필요 조건 | 위험도 | 부작용 | 충돌 방식 |
|---|---:|---|---|---|---:|---|---|
| 의심 | 15~34 | 말풍선, 댓글, 소수 따라 하기 | 회색/노랑 아이콘 | 조회수 발생 | 낮음 | 작은 오해 | 충돌 없음 또는 농담 |
| 유행 | 35~54 | 집단 행동, 상품 구매, 챌린지 | 노랑 오버레이 | 특정 집단 믿음 | 중간 | 품절/신고 | 같은 구역 소문과 경쟁 |
| 상식 | 55~74 | NPC가 당연하게 행동 | 주황 뉴스 배너 | 반복 노출/기자 관심 | 높음 | 기관 반응 | 반대 소문과 충돌 |
| 법칙 | 75~100 | 실제 규칙, 출입 제한, 검문 | 빨강 도장 연출 | 핵심 집단 믿음 + 상태값 조건 | 매우 높음 | 규칙 붕괴 | 우선순위 판정 |

## 확산 영향 요소
- 쇼츠 자극도: 초기 조회수와 공유를 올린다.
- 신뢰도: 상식/법칙 단계로 갈 때 중요하다.
- 조회수: 의심/유행 단계 가속.
- 대상 NPC 집단: 태그 선호와 확산력 반영.
- 반복 노출: 단계 상승 보정, 피로도도 증가.
- 기존 마을 분위기: 혼란도가 높으면 자극 소문이 잘 퍼진다.
- 반박 뉴스: 믿음 단계 하락 또는 밈화 선택지 발생.
- NPC 성향: 학생은 유행, 공무원은 법칙화, 기자는 뉴스화를 돕는다.
- 기관 개입: 법/체포 태그를 강화하지만 실패 위험도 높인다.
- 라이벌 루머: 확장/멀티에서 같은 상태값을 두고 경쟁한다.

# M. 소문 충돌 시스템

## 충돌 우선순위
1. 법칙 단계 소문이 상식 이하 소문보다 우선한다.
2. 같은 단계면 관련 NPC 집단의 믿음 총합이 높은 쪽이 우선한다.
3. 엔딩 목표와 직접 연결된 태그는 최종일에 약한 보정을 받는다.
4. 기관 관련 소문은 관공서/경찰 구역에서 우선한다.
5. 유행 관련 소문은 학교/광장에서 우선한다.

## 병맛 해석 예시
- 바나나 없는 고양이는 투표 가능한가? → 고양이 특권 vs 바나나 신분증 충돌.
- 문어 시장은 시민인가? → 시장 권위 vs 문어 의심도 충돌.
- 경찰은 누구를 체포하는가? → 체포 조건 카드와 시민권 카드 우선순위 충돌.

## 플레이어 악용 방법
- 상대 엔딩 태그와 내 엔딩 태그를 일부러 충돌시켜 부작용을 유도한다.
- 낮은 신뢰도 소문을 던져 팩트체크를 낭비시킨다.
- 법칙화 직전 소문을 다른 구역에서 터뜨려 우선권을 가져온다.

# S. MVP 범위

## 포함
- 엔딩 3개.
- 소문 카드 40~60장, 권장 54장.
- NPC 타입 6~8개, 권장 8개.
- 마을 구역 5개.
- 믿음 단계 4단계.
- 하루 제한 7일.
- 부작용 15개 이상.
- 쇼츠 업로드 UI.
- 하루 종료 리포트.
- 엔딩 화면.

## 제외
- 온라인 멀티.
- 완전 자유 입력.
- 무한 절차 생성.
- 복잡한 경제 시뮬레이션.
- 실시간 3D 오픈월드.
- 정치/현실 인물 패러디.
- 실제 뉴스/현실 이슈 직접 반영.

# T. 개발 로드맵

| 주차 | 목표 | 산출물 | 검증 기준 |
|---:|---|---|---|
| 1~2 | 카드 조합/소문 생성 | 데이터 스키마, 조합 코어 | 20개 이상 조합 출력 |
| 3~4 | NPC 믿음 확산 | NPC 타입, 믿음 단계 | 단계 상승 테스트 통과 |
| 5~6 | 마을 상태/부작용 | 상태값 12개, 부작용 15개 | 태그 기반 부작용 발생 |
| 7~8 | 엔딩 3종 | EndingEvaluator, 컷신 1차 | 3개 엔딩 강제 달성 |
| 9~10 | UI/연출/사운드 | 전체 흐름 UI, 효과음 | 새 게임부터 엔딩까지 연결 |
| 11 | 밸런싱/재미 검증 | 자동 시뮬레이터, 테스트 빌드 | 첫 웃음/이해도 기준 확인 |
| 12 | 데모 빌드 | 패키징, 버그 수정 | 외부 PC 실행 가능 |

# U. 밸런스 기준

- 엔딩은 한두 번의 대박 조회수로 열리지 않는다.
- 1일차에도 반드시 작은 반응이 보여야 한다.
- 부작용은 카드 태그와 상태값에서 발생해 납득 가능해야 한다.
- 플레이어는 업로드 전 예상 영향과 위험을 봐야 한다.
- 실패 리포트는 웃겨야 한다.
- 결과는 70% 예측 가능, 부작용은 30% 비틀기를 목표로 한다.

| 구간 | 목표 확산 |
|---|---|
| 1일차 | 의심 단계와 첫 행동 변화 |
| 2일차 | 유행 단계 도달 가능 |
| 3~4일차 | 상식 단계 도달 가능 |
| 5~6일차 | 법칙 단계 도달 가능 |
| 7일차 | 마지막 조합으로 성공/실패 갈림 |

# W. 확장 콘텐츠

## 후보
- 친구끼리 루머 전쟁 모드.
- 신규 엔딩팩.
- 신규 마을 구역.
- 신규 NPC 집단.
- 신규 소문 카드팩.
- 시즌 이벤트.
- 스트리머 채팅 투표 모드.

## 루머 전쟁 모드
- 2~4인.
- 각자 비밀 엔딩 목표 보유.
- 같은 마을 상태값 공유.
- 동시에 소문 업로드.
- 서로의 소문 충돌.
- 먼저 최종 엔딩을 달성한 플레이어 승리.
- 시청자는 중립 NPC 여론으로 투표 가능.

# X. 리스크와 대응

| 리스크 | 대응책 |
|---|---|
| 자유도가 너무 높아 개발 불가 | 자유 입력 금지, 카드 3축/태그 테이블로 제한 |
| AI 생성물이 재미없음 | AI 없이도 작동하는 템플릿 문구 보유 |
| 정치/현실 이슈 오해 | 완전 가상 마을, 금지어 검증기, 실존 인물 금지 |
| 카드 조합 반복 | 희귀도, 해금, 부작용, 시작 분위기 변주 |
| NPC 행동 변화가 안 보임 | 말풍선/소품/오브젝트 변화 우선 구현 |
| 시스템이 복잡함 | 선택 엔딩 관련 수치 3개만 크게 표시 |
| 병맛은 있는데 게임성이 약함 | 엔딩 체크리스트, 위험/보상, 팩트체크, 충돌 강화 |
| 1인 개발 범위 초과 | MVP 범위 밖은 post-MVP로 이동 |
