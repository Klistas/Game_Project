# GDD — 스티커 월드

> 기준 문서: `docs/04_GDD_StickerWorld.md`

## 현재 방향

스티커 월드는 사물과 NPC에 속성 스티커를 붙여 세계의 반응을 바꾸는 병맛 퍼즐 샌드박스다.

이번 Unity 폴더의 1차 목적은 전체 게임 구현이 아니라, `TagInteraction Framework`의 얇은 골격을 만들고 G0 프로토타입의 기반을 준비하는 것이다.

## 핵심 루프

```text
목표 확인
→ 대상 관찰
→ 제한된 스티커 부착
→ 태그 변경
→ 규칙 해석
→ 반응/연쇄 상호작용
→ 목표 달성 또는 대참사
```

## G0 범위

- 스티커 5종: 졸림, 폭발, 왕, 개, 작음
- 오브젝트/NPC 8종: 플레이어, 경비원, CCTV, 문, 벽, 금고, 고양이, 의자
- 은행 테마 3-5스테이지
- 외부 에셋 없음
- 태그/규칙/반응 엔진은 데이터 주도 구조 유지

## 하지 않는 것

- 최종 아트
- 전체 60스테이지
- 워크샵/에디터 공개
- 외부 에셋 임포트
- 런타임 AI 호출
