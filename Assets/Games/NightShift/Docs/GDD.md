# GDD — 새벽의 편의점 (가칭: NIGHT SHIFT: LAST CONVENIENCE)

> 장르: 규칙 기반 관찰 호러 (원 메커닉 소품) | 가격: ₩5,500 / $3.99 | 기간: 8~12주 | 플랫폼: Steam(PC)
> 엔진: Unity 6 (2D 픽셀 또는 3D 로우폴리+CRT 필터, Phase 0에서 결정) | 언어: KO/EN/JP

---

## 0. 원 센텐스 피치

**"새벽 2~6시 편의점 알바. 본사에서 내려온 '야간 근무 수칙'을 지키며, 손님 중 인간이 아닌 것을 구별해 살아남는 4박의 관찰 호러."**

(수칙 예: "젖은 발자국을 남기는 손님에게는 거스름돈을 손으로 건네지 마시오", "새벽 3시 33분에 들어온 손님과 눈을 마주치지 마시오", "본인 얼굴과 같은 손님이 오면 창고 문을 잠그시오")

### 시장 근거
- 벅샷 룰렛 모델(원 메커닉 단편 호러, $2.99, 800만 장)이 증명한 "짧고 강렬한 저가 호러" 수요
- 관찰/판별 호러(Observation Duty류, The Closing Shift, 이상한 손님류)는 **스트리머 리액션 콘텐츠와 완벽 호환** — 판별 실패 순간의 비명 = 무료 마케팅
- "한국 편의점 + 괴담" 소재는 글로벌에 신선 (K-호러 프리미엄) + 국내 커뮤니티/유튜브 확산력
- 콘텐츠가 "수칙 × 손님 변형" 조합이라 데이터 주도로 물량 생산 용이 → Claude Code와 궁합 최상

### 리스크
- 유사 장르 포화 → 차별화 포인트: ①**수칙이 밤마다 갱신·모순되며 어떤 수칙은 거짓**(본사가 수상하다는 메타 서사) ②판별이 아니라 "응대 절차" 수행이 메커닉 (긴장 지속시간 증가)
- 호러 연출 역량 필요 → 사운드 디자인에 예산/시간 집중

## 1. 코어 루프

```
[근무 시작] 오늘 밤의 수칙서 확인 (기존 수칙 + 신규/개정 수칙)
 → 손님 입장 (외형·행동·소리에 단서)
 → 관찰: CCTV, 카운터 시점, 거울, 온도계 등 도구로 단서 수집
 → 응대 절차 선택: 정상 응대 / 특수 절차(수칙 이행) / 거부·퇴거 / 숨기
 → 판정: 올바른 절차 → 무사 / 오판 → 경고 or 즉사(밤 재시작)
 → 새벽 6시 생존 → 급여 정산 + 본사 팩스(서사 진행) → 다음 밤
[전체] 4박 + 진엔딩 조건(숨겨진 수칙 발견) / 엔딩 3종
```

**플레이타임:** 본편 2.5~4시간 + 진엔딩/도전과제 리플레이. (이 가격대 적정: 벅샷 룰렛 기준선)

## 2. 시스템 설계

### 2.1 손님 시스템 (콘텐츠 축)
- `CustomerSO`: 외형 프리팹 + 이상 징후 조합(anomaly 리스트) + 올바른 응대 절차 + 오판 결과 등급
- **이상 징후 풀 30종** (조합형): 젖은 발자국, 그림자 없음, 거울에 안 비침, 깜빡임 없음, 대사 역재생, 냉장고 앞 정지, 시계와 다른 손목시계, 플레이어 명찰과 같은 이름 등
- 정상 손님 15종 + 괴이 12종. **정상인데 수상해 보이는 손님**(레드 헤링)이 공포의 핵심
- 밤별 스폰 테이블 = 데이터. 4박 난이도 곡선: 징후가 점점 미세해짐

### 2.2 수칙 시스템 (차별화 핵심)
- 수칙서 UI(종이 질감, 항상 열람 가능). 밤마다 팩스로 추가/개정 수칙 도착
- 수칙 데이터: `RuleSO` — 조건(징후 태그), 요구 절차, 진위 여부(거짓 수칙!), 획득 밤
- **거짓 수칙 기믹:** 3밤차부터 일부 수칙이 오히려 괴이를 부름 → 손글씨 메모(전임 알바의 경고)와 교차 검증해야 함 → 진엔딩 열쇠

### 2.3 응대 절차 (원 메커닉의 몸통)
- 절차 = 미니 인터랙션 시퀀스: 바코드 스캔, 거스름돈(트레이 vs 손), 봉투 담기, 신분증 요구, 온장고 물건 권유, 소금 뿌리기(특수)
- 괴이별로 "절차 중 특정 단계를 다르게" 해야 함 → 아는 것과 손이 떨리는 것의 간극이 공포
- 입력은 마우스 온리 (스팀덱/접근성)

### 2.4 서사 & 엔딩
- 환경 스토리텔링: 팩스, 전단지, 라디오 뉴스, 전임 알바 메모. 컷신 없음
- 엔딩 3종: 만기 퇴직(노멀) / 실종(배드, 누적 경고) / 진실(트루, 숨겨진 수칙 5개 발견)
- 도전과제 15개: "무경고 클리어", "모든 괴이 도감", "3시 33분 생존" 등

## 3. 아트/사운드 방향

- **비주얼 결정 (Phase 0):** A안 2D 픽셀(제작 빠름, Ludo.ai 활용) vs B안 3D 로우폴리 + PSX/CRT 필터(호러 체감 우수, 무료 에셋 풍부). 권장: **B안** — 편의점 에셋은 구매 가능, 손님만 제작하면 됨
- 카메라: 카운터 고정 시점 + CCTV 전환 (제작비 절감 + 관찰 게임 문법)
- **사운드가 공포의 70%:** 새벽 편의점 앰비언스(냉장고 험, 형광등, 자동문 차임), 괴이별 시그니처 사운드(단서이자 공포). 편의점 차임 변조가 시그니처 연출
- 캡슐: 새벽 편의점 창밖에서 안을 들여다보는 실루엣 + 형광등 역광

## 5. 개발 로드맵 (Claude Code Phase)

### Phase 0 — 셋업 & 비주얼 결정 (세션 1회)
- [ ] 프로젝트/Git/폴더 규약, EventBus/SaveSystem 이식
- [ ] A/B 비주얼 목업 각 1장면 → 스크린샷 비교 후 결정 (지인 투표)
- [ ] `CustomerSO`, `RuleSO`, `AnomalySO`, `NightSpawnTableSO` 스키마 + CSV 임포트
- **DoD:** 비주얼 방향 확정, 더미 손님 1명이 입장→퇴장 상태머신으로 동작

### Phase 1 — 응대 루프 (세션 2회)
- [ ] 손님 상태머신 (입장→진열대 배회→카운터→응대→퇴장/돌변)
- [ ] 응대 절차 인터랙션 4종 (스캔, 거스름돈 선택, 봉투, 퇴거 요청)
- [ ] 판정 시스템: 절차 로그 vs 정답 절차 비교 → 무사/경고/사망
- [ ] 사망 연출 1종 (암전 + 사운드, 점프스케어는 절제)
- **DoD:** 괴이 2종 판별 루프가 성립 → 스스로 플레이 시 긴장되는가 → **G0 게이트**
- **Claude Code 지시:** "손님 행동과 판정은 전부 SO 데이터 참조. 신규 괴이 추가 시 코드 무수정이 목표"

### Phase 2 — 수칙 & 관찰 도구 (세션 2회)
- [ ] 수칙서 UI(팩스 수신 연출), CCTV 전환, 거울/온도계 단서 시스템
- [ ] 밤 진행: 시계(2:00→6:00 압축 30~40분), 스폰 테이블 구동, 급여 정산
- [ ] 앰비언스 사운드 레이어 + 괴이 시그니처 사운드 3종
- **DoD:** 1밤 풀 루프 완성, 첫 테스트 5명 중 3명 이상 "무서웠다/한 밤 더" → **G1 게이트**

### Phase 3 — 스팀 페이지 & 데모 (세션 1~2회)
- [ ] 데모 = 1밤 완결판 (호러는 데모→구매 전환율이 높은 장르)
- [ ] 캡슐 3안, 트레일러(스트리머 리액션 스타일 편집), 페이지 KO/EN
- [ ] Scream Fest 등 호러 계열 스팀 이벤트 신청
- **DoD:** 페이지 라이브, 데모 클립 쇼츠 주 2회 → **G2 트래킹 (기준 500/4주)**

### Phase 4 — 프로덕션 (세션 5~7회)
- [ ] 4밤 전체, 괴이 12종, 수칙 20종(거짓 수칙 + 메모 교차검증), 엔딩 3종
- [ ] 괴이 도감(클리어 후 해금), 도전과제 15개
- [ ] 난이도 텔레메트리: 밤별 사망 지점 로컬 로그 → 테스터 데이터로 밸런스
- **DoD:** 테스터 완주율 60%+ (호러 소품 적정), 진엔딩 힌트 도달률 검증

### Phase 5 — 출시 (세션 1~2회)
- [ ] 스트리머 키 150+ (국내외 호러 전문 채널 — 이 장르는 스트리머가 전부)
- [ ] 출시 타이밍: 가능하면 10월(할로윈 시즌) 정조준
- [ ] 출시 2주 후 무료 업데이트 "5번째 밤" 예고 (리뷰 모멘텀 + 재방문)

## 6. Kill 체크
- G0에서 "만든 나조차 안 무서움" + 테스터도 동일 → 사운드 리워크 1회 후 재실패 시 Kill
- G2 위시리스트 미달이어도 할로윈 시즌 출시 가치가 있으므로 스코프를 3밤으로 줄여 $2.99 출시로 전환 (완전 Kill보다 회수 우선)
