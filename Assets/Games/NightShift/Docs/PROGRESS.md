### ✅ 비주얼 결정: **B안 — 3D 로우폴리 + PSX/CRT 필터** (2026-07-07 확정)
- 근거: CRT/PSX 특유의 지글거리는 화면 자체가 공포를 만듦(Puppet Combo/백룸 계열 문법), 편의점 3D 에셋은 구매 가능 → 손님만 제작하면 됨, "무서운 캡슐 이미지 = 매출"인 장르 특성
- 아트 규격(추후 에셋 교체 시): 로우폴리 편의점 셸 + 손님 로우폴리 피규어(몸+머리), 카운터 고정 시점 원근 카메라, 형광등 역광, 전면 CRT 포스트 필터 상시
- G0 게이트는 Phase 1(사운드 포함) 완료 후 판정 — 사운드가 공포의 70%

## Phase 1 — 응대 루프 + 비주얼/사운드 (구현 완료: 2026-07-07)

> 피드백 "단조롭다"에 대응: 관찰(능동 발견) + CRT 비주얼 + 사운드로 세 축 보강

- [x] **CRT/PSX 포스트 필터** (`Shaders/CrtFilter.shader` + `CrtPostProcess.cs`): 2카메라 RT 파이프라인, 배럴왜곡+색수차+스캔라인+비네트+그레인+플리커. 강도 튜닝 완료(1차 과다 → 조정)
- [x] **3D 로우폴리 씬**: 편의점 셸(바닥/벽/선반/카운터/형광등 바) + 손님 리그(캡슐 몸+구 머리), 점광 형광등 + 안개, 카운터 고정 시점
- [x] **관찰 도구** ([C]CCTV [V]거울 [B]온도계): 징후를 텍스트로 다 보여주지 않고 `AnomalySO.revealedBy`로 도구 확인해야 발견 → 능동적 긴장. 거울 괴이는 거울로만 드러남(검증 완료)
- [x] **프로시저럴 사운드** (`NightAudio.cs`): 냉장고 험+형광등 버즈 앰비언스 루프, 자동문 딩동, 괴이 시그니처 화이닝, 사망 스팅, 무사/경고 블립
- [x] **사망 암전** (`DeathPresentation.cs`): CRT `_Fade`로 풀스크린 암전(스프라이트 방식 실패 → 셰이더 방식으로 교체), 점프스케어 절제
- [x] 검증: 컴파일/플레이 에러 0, 테스트 6/6, 관찰→응대→판정→사망암전 E2E 확인 (스크린샷)

> 피드백 "목업단계보다 비주얼·상호작용·이벤트 더 필요"에 대응

- [x] **손님 생동감** (`CustomerAnimator.cs`): 아이들 호흡/스웨이 + 괴이별 미동작(무깜빡임=머리 틱, 젖은/차가운=천천히 다가옴)

- [x] **밤 시계 + 이벤트 디렉터** (`NightClock.cs`, `NightDirector.cs`): 02:00→06:00 진행, 손님2 처리 시 팩스로 신규 수칙 도착, 손님3 처리 시 정전 스케어(글리치+정전+시그니처음)
